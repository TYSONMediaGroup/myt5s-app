The official desktop and web portal application for the myT5S ecosystem, built with React 19, TypeScript, Vite, and Electron.

---

## Getting Started

### Development

```bash
# Run web client
npm run dev

# Run desktop Electron client
npm run electron:start
```

### Build & Package

```bash
# Production web bundle
npm run build

# Package Electron desktop app
npm run electron:build
```
